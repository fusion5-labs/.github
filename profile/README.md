## 🎭 About StageLink
**StageLink** is an AI-powered two-sided live event marketplace platform connecting **Customers** (event organizers, hotels, restaurants, individuals), **Artists** (singers, bands, DJs, dancers), and **Renters** (sound, lighting, and stage equipment hire stores) on a single unified platform.
